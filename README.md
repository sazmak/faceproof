# FaceProof

Проект по ICT, Assignment #2. Направление: Computer Vision. Вариант B: улучшить датасет и сравнить результаты.

**Идея.** Детекторы «настоящее лицо или ИИ» плохо ловят лица из генераторов, которых не было в обучении. Мы добавляем в обучающий набор 314 новых сгенерированных лиц и измеряем, насколько лучше детектор ловит фейки нового генератора.

## Что в репозитории

| Файл | Что это |
|---|---|
| `index.html` | Лендинг и MVP-интерфейс: эксперимент и проверка одного фото. Работает в браузере, без установки. |
| `docs/RESEARCH.md` | Обзор моделей и датасетов для детекции ИИ-лиц. |
| `JOURNAL.md` | Журнал: что сделано на каждом шаге. |

## Метод

Детектор сделан по рецепту UnivFD (Ojha et al., CVPR 2023): замороженный энкодер CLIP и обучаемый линейный классификатор поверх его признаков. Между двумя версиями меняются только данные.

| Версия | Обучающие данные |
|---|---|
| Baseline | настоящие лица + фейки из открытого датасета |
| Improved | то же + наши новые фейки (80% от 314) |

Обе версии проверяются на одном отложенном тесте (20% каждой папки, seed 42): настоящие, старые фейки, новые фейки. Метрики: доля пойманных новых фейков, доля пойманных старых, доля настоящих без ложной тревоги, balanced accuracy, accuracy, ROC AUC.

## Как запустить

1. Открыть `index.html` в Chrome или Edge (нужен интернет: при первом запуске скачивается энкодер CLIP, около 90 МБ).
2. Выбрать три папки: настоящие лица, фейки из открытого датасета, наши 314 фейков.
3. Нажать **Run experiment**. На ноутбуке без видеокарты примерно 900 фото считаются несколько минут.
4. Нажать **Export results.json** и положить файл в `results/`.
5. В блоке **Try the detector** загрузить любое фото лица.

Данные: настоящие и «старые» фейки берём из открытого набора [140k Real and Fake Faces](https://huggingface.co/datasets/TheKernel01/140k-Real-and-Fake-Faces) (70 тыс. FFHQ и 70 тыс. StyleGAN), по 300 штук каждого класса достаточно.

## Сценарий выступления (7 минут)

1. Проблема (1 мин): детекторы не узнают новые генераторы. Цифры из обзора в `docs/RESEARCH.md`.
2. Идея и вариант B (1 мин): меняем данные, а не модель.
3. Метод (1,5 мин): CLIP + линейная голова, что такое baseline и improved, как делится тест.
4. Результаты (2 мин): таблица и столбики из блока Experiment.
5. Демо (1 мин): загрузить фото в Try the detector.
6. Ограничения и что дальше (0,5 мин).

## Ограничения

- Тест маленький (около 60 новых фейков), поэтому разница в несколько процентов может быть случайной.
- Новые фейки в обучении и в тесте сделаны одним генератором. Это показывает адаптацию к этому генератору, а не ко всем будущим.
- Оценка детектора является вероятностью, а не доказательством.
