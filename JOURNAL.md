# Журнал проекта

## 13.11.2026

Время по часам ноутбука, местами с точностью до пары минут.

**До начала.** Выбран вариант B. Сгенерированы фото несуществующих людей. Выбран слот для презентации.

**10:52. Проверка ноутбука.** Нет Python, Node.js, GitHub CLI и видеокарты, 8 ГБ памяти, git установлен.

**10:54. Решение по методу.** Python и PyTorch на этой машине недоступны. Выбран метод UnivFD: замороженный CLIP и линейный классификатор. Считается в браузере через transformers.js.

**10:55. Ресерч.** Бенчмарки 2025–2026, готовые модели, датасеты, работы про few-shot дообучение. Итог в `docs/RESEARCH.md`.

**10:56–10:58. Первая версия.** `index.html`, README, локальный git, первый коммит.

**10:59. Проверка кода на 72 синтетических картинках.** Всё отработало без ошибок. Цифры этого прогона к проекту не относятся и удалены.

**11:04. Данные.** Получен архив `Подборка без названия.zip`: 420 JPG 1024×1024, 310 МБ, восемь категорий промптов по именам файлов. Распакован в `data/fake`.

**11:07–11:10. Настоящие лица.** Скачаны 420 фото с меткой `real` из открытого набора 140k Real and Fake Faces (FFHQ, 256×256, 4,6 МБ) в `data/real`. По просьбе автора проекта скачаны только настоящие, без старых фейков.

**11:12. Просмотр примеров.** Наши фото это портреты по пояс и в полный рост, FFHQ это плотно обрезанные лица. Без выравнивания классификатор отличал бы кадрирование, а не ИИ. Решение: одинаково вырезать лицо во всех фото.

**11:14. Разбиение.** `splits/split.json`, seed 42, 20% в тест, для ИИ-лиц стратификация по категории промпта. 334 + 86 в каждом классе, пересечений нет.

**11:15. Смена схемы сравнения.** Старых фейков нет, поэтому «до улучшения» это готовый открытый детектор (Deep-Fake-Detector-v2, ONNX) и CLIP без обучения. «После» это наш классификатор на новых данных. Добавлена кривая по числу обучающих фото.

**11:18–11:22. Две ошибки в вырезании лиц, найдены по просмотру примеров.**
1. На фото в полный рост лицо не находилось. Добавлен поиск по перекрывающимся фрагментам.
2. Правило «самая большая рамка» выбирало ложные срабатывания (сумка, фон). Заменено на «самое уверенное срабатывание, не ниже 0,75, лицо не меньше 80 пикселей». Фото без такого лица исключаются.

**11:23–11:44. Прогон эксперимента.** 840 фото, около 21 минуты.

**Результат.** Тест: 73 ИИ-лица и 86 настоящих.

| Детектор | Accuracy | Поймано ИИ | Настоящие верно | AUC |
|---|---|---|---|---|
| Готовый открытый детектор | 54,7% | 60,3% | 50,0% | 0,519 |
| CLIP без обучения | 57,2% | 43,8% | 68,6% | 0,617 |
| Наш, на новых данных | 98,7% | 98,6% | 98,8% | 0,997 |

Кривая: 5 фото дают 86,7%, 10 фото 96,0%, 100 фото 98,1%, все 278 дают 98,7%.

Исключено 69 из 420 наших фото (нет лица нужного размера), все 420 настоящих вошли.

**Оговорка.** 96% на 10 фото говорит о том, что классы разделяются слишком легко. Вероятная причина: разница в стиле фото между FFHQ и нашими портретами. Это записано в ограничениях.
