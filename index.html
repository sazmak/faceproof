Detectors miss faces from generators they have never seen. We fix that with data.

FaceProof takes a real-vs-AI face detector, adds a new set of 314 AI-generated faces to its training data, and measures how much better it catches fakes from the new generator.

How it works

The detector follows the UnivFD recipe (Ojha et al., CVPR 2023): a frozen CLIP image encoder and a small trainable linear classifier on top. Only the training data changes between the two versions.

01 · ORIGINAL DATASET

Baseline detector

Trained on real faces and fakes from an open dataset (older generator).

02 · ENRICHED DATASET

Improved detector

Same model, same settings. Training set extended with our newly generated faces.

03 · COMPARISON

Same held-out test

Both versions are scored on images neither has seen: real, old fakes, new fakes.

Limits

A detector score is evidence, not proof. Results depend on the generators and photo styles in the training data, the test set is small, and heavy compression or editing can change the answer. Numbers on this page come only from the experiment you run here.
